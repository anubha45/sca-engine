# sca-engine
This is a Self-Consistency Answer Engine

It takes your question query or thought and sends to 3 different models, retrieves the responses, filter the useful information and process all the 3 outputs to a more capable model, it doesn't filters out the best but its more into it.

It evaluates all the responses gives reviews on every response then, combines all, process and makes the best out of everything collected.

This works on Openrouter Api key.
You just have to create a openrouter api key and make a .env file save the key as OPENROUTER_API_KEY. 
and its all good to go!
